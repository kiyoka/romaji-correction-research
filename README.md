# ローマ字タイプミス自動修正実験

iPhoneなどの小さいデバイス上のQWERTYキーボードでのタイプミスを、LLMを使って自動修正する研究プロジェクトです。

GPT-5.2とApple Intelligence（オンデバイスLLM）でローマ字タイプミス修正を測定しました。Apple側はmacOS 26.2と27.0で同じ条件の再測定を行っています。GPT側の過去の結果とはプロンプトとケース集合が異なります。

**Apple Foundation Models最新結果（macOS 27.0、2026-09-19）:**
- 完全一致率: **67.39%（31/46）**。同じ設定で2回実行し、どちらも31件正解
- macOS 26.2の測定と共通する45件では、**46.67%（21/45）→ 68.89%（31/45）**
- 内訳（46件）: 実データ2/8、仮想データ8/10、固有名詞21/28
- 平均応答時間: 1回目1.13秒、連続した2回目0.74秒。速度の変化はこの2回だけでは判断しない
- 結果ファイルと測定条件は `RESULT.md` の「macOS 27.0での追加計測」を参照

**過去のmacOS 26.2での結果（プロンプト改善＋データリーク修正後）:**
- 完全一致率: **46.67%（21/45）**（初期28.57% → データリークを含むV6の64.44% → 修正後46.67%）
- **重要な発見**: プロンプトのexamplesにテストデータと同じ内容を含めると**データリーク**が発生し、結果が過剰に良く見える問題を発見・修正しました
- 詳細な比較グラフとデータリーク問題の分析は `RESULT.md` を参照

macOS 27.0では測定値が上がりましたが、実データ由来のタイプミスは2/8件しか正解できませんでした。GPT-5.2の過去の結果は97.62%（41/42）です。ただしプロンプトとケース集合が異なるため、厳密なモデル間比較ではありません。これはMac上の独立したベンチマークであり、iOS版Sumibiの実機検証ではありません。

## セットアップ

### 1. 環境変数の設定

```bash
cp .env.example .env
# .envファイルにOPENAI_API_KEYを設定してください
```

### 2. 仮想環境のセットアップと依存関係のインストール

```bash
make setup
```

または手動で：

```bash
# 仮想環境の作成
python3 -m venv venv

# 仮想環境の有効化
source venv/bin/activate  # Linux/macOS
# または
venv\Scripts\activate     # Windows

# 依存関係のインストール
pip install --upgrade pip
pip install -r requirements.txt
```

## 実験の実行

```bash
make run
```

実験結果は`results/`ディレクトリに保存されます。
